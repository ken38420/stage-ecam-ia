# Mise en place sur ChatGPT

Deux options. Les menus peuvent changer : cherche l'équivalent si un bouton a bougé.

## Option A — Projet ChatGPT (recommandé)
1. Barre latérale → **Nouveau projet** → nomme-le « Stage de fin d'études ».
2. Ouvre les **instructions du projet** et colle tout le contenu de `PROMPT.md`.
3. Ajoute dans les **fichiers du projet** : les 4 fichiers de `fichiers/`, les 2 de `modeles/` et ton CV.
4. Nouvelle conversation dans le projet → « Commence l'onboarding ».

## Option B — GPT personnalisé
1. **Explorer les GPT** → **Créer** → onglet **Configurer**.
2. **Instructions** : colle `PROMPT.md` (il tient dans la limite de caractères).
3. **Connaissances** : ajoute les fichiers de `fichiers/` et `modeles/`. Joins ton CV dans la conversation plutôt que dans le GPT si tu comptes le partager.
4. Coche **Recherche web** (utile pour l'accroche des lettres) et **Interpréteur de code** si tu veux tenter le format PDF.

## Bon à savoir
- ChatGPT ne modifie pas les fichiers du projet : recopie le bloc « 📌 À COPIER DANS TES FICHIERS » dans tes `.md`, puis remplace-les dans le projet.
- Format PDF : l'interpréteur de code n'a pas toujours LaTeX installé. Si ça échoue, passe en LaTeX + [Overleaf](overleaf.md).
