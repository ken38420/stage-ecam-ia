# Contribuer

Le kit s'améliore avec les retours de chaque promo.

## Ce qui est utile
- **Colorations** : corriger ou compléter `fichiers/colorations_ecam.md` selon le programme réel de ta promo (outils, plateformes, projets). C'est le fichier le plus utile à tenir à jour.
- **Banques de mots-clés** : un nouveau secteur dans `fichiers/methode_candidature.md` §3 (format [A] / [V] / angle narratif). Pas de [P] : ils sont propres à chaque étudiant.
- **Guides** : une IA testée, un menu qui a changé.
- **Règles** : une consigne mal suivie par une IA, une meilleure formulation dans `PROMPT.md`.
- **Modèles** : améliorations de `modele_CV.tex` / `modele_LM.tex`, tant qu'ils restent une colonne, une page et compatibles ATS.

## Règles
- **Aucune donnée personnelle** : ni nom, ni CV, ni profil rempli, ni candidature réelle.
- `PROMPT.md` doit rester sous 8 000 caractères (limite des GPT personnalisés).
- Teste ta modification sur au moins une IA avant d'ouvrir la pull request, et indique laquelle.

## Comment faire
1. Fork → branche → modification → pull request avec une phrase d'explication.
2. Ou ouvre simplement une **issue** pour signaler un problème ou proposer une idée.
