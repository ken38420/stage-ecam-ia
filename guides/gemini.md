# Mise en place sur Gemini

Les menus peuvent changer : cherche l'équivalent si un bouton a bougé.

## Avec un Gem (recommandé)
1. Barre latérale → **Explorer les Gems** → **Nouveau Gem** ; nomme-le « Stage de fin d'études ».
2. **Instructions** : colle tout le contenu de `PROMPT.md`.
3. **Connaissances** : ajoute les 4 fichiers de `fichiers/`, les 2 de `modeles/` et ton CV (depuis ton ordinateur ou Google Drive).
4. Enregistre, ouvre le Gem → « Commence l'onboarding ».

## Bon à savoir
- Si l'import d'un `.md` ou d'un `.tex` est refusé, renomme-le en `.txt`, le contenu reste lisible.
- Si tes fichiers sont dans Google Drive, la mise à jour est plus simple : tu modifies le fichier dans Drive et le Gem lit la nouvelle version (sinon, recopie le bloc « 📌 À COPIER DANS TES FICHIERS » et remplace le fichier).
- Format PDF : en général non disponible, choisis LaTeX + [Overleaf](overleaf.md).
