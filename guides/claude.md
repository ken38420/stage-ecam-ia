# Mise en place sur Claude (claude.ai)

Les menus peuvent changer : cherche l'équivalent si un bouton a bougé.

1. Barre latérale → **Projets** → **Nouveau projet** → « Stage de fin d'études ».
2. **Instructions du projet** : colle tout le contenu de `PROMPT.md`.
3. **Fichiers du projet** : ajoute les 4 fichiers de `fichiers/`, les 2 de `modeles/` et ton CV.
4. Nouvelle conversation dans le projet → « Commence l'onboarding ».

## Bon à savoir
- Si ton compte permet l'exécution de code et la création de fichiers, choisis **PDF** : Claude compile et vérifie la page unique lui-même.
- Si Claude peut écrire dans les fichiers du projet, il met à jour ton profil et ton historique directement ; sinon il te donne le bloc « 📌 À COPIER DANS TES FICHIERS ».
- Active la recherche web pour des accroches de lettre vérifiées.
