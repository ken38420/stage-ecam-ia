# Colorations et pathways ECAM LaSalle — base de compétences

> **Usage par l'IA** : l'étudiant choisit sa coloration (ou son pathway) au démarrage. Tu affiches la **liste à cocher** correspondante en un seul message. Chaque élément coché devient une compétence confirmée avec son contexte (`C` = cours, `P` = TP / projet / mini-projet). Un élément non coché **n'est jamais revendiqué**, même s'il figure au programme.
> Tout ce qui vient de la coloration se présente comme **formation** (« en cours », « en projet de coloration »), jamais comme expérience en entreprise.
>
> **À vérifier** : ce fichier a été rédigé à partir d'un guide non officiel. Les programmes évoluent d'une promo à l'autre. Corrections bienvenues (voir `CONTRIBUTING.md`).

## Cursus
| Cursus | Langue | Spécialisation |
|---|---|---|
| **ECAM Arts et Métiers** (ingénieur généraliste) | Français | Coloration (~10 % du cycle ingénieur, 4e et 5e années) |
| **ECAM Engineering** (Génie Électrique et Mécanique) | Anglais | Pathway (~40 % dès la 3e année), double diplôme |

Les formations par alternance (Génie Industriel et Mécanique, Énergétique, Systèmes Numériques et Génie Industriel) ne passent pas par un stage de fin d'études : ce kit ne les couvre pas directement, mais il reste utilisable pour une recherche d'emploi.

## A. Colorations — ECAM Arts et Métiers

### A1. Matériaux et Structures Avancées (MAS)
**Mots-clés ATS** : conception mécanique, calcul de structures, éléments finis (FEA/MEF), ANSYS, optimisation topologique, fabrication additive (DfAM), analyse modale, vibrations, matériaux, métallurgie, traitements thermiques, caractérisation, analyse de défaillance, ACV / éco-conception.
**À cocher (C / P / rien)** :
- [ ] Optimisation topologique (ex. challenge conception → impression 3D → essai de rupture)
- [ ] Calcul FEA sous ANSYS (non-linéaire, contact, thermo-mécanique)
- [ ] Analyse modale / vibratoire, numérique ou expérimentale (accéléromètres, pot vibrant)
- [ ] Fabrication additive métal ou polymère (LPBF, SLS, FDM… — plateforme SINTERPRINT)
- [ ] Traitements thermiques / métallurgie
- [ ] Caractérisation : MEB / EDS, DRX, spectrométrie, essais Charpy
- [ ] Analyse de défaillance
- [ ] ACV, éco-audit, indices de performance matériaux
- [ ] Projet de R&D (PRD) avec un industriel → préciser le sujet en une ligne
**Métiers cibles** : ingénieur calcul / simulation, conception mécanique, matériaux, R&D, fabrication additive, qualité fournisseurs (aéro, spatial, défense, auto, médical).

### A2. Advanced Software and Hardware (ASH)
**Mots-clés ATS** : systèmes embarqués, C, C++, Python, microcontrôleurs (STM32, ARM Cortex-M), RTOS, temps réel, bus CAN, Modbus, Ethernet industriel, IoT, LoRaWAN, MQTT, traitement du signal, acquisition de données, industrie 4.0.
**À cocher (C / P / rien)** :
- [ ] Programmation C / C++
- [ ] Programmation Python
- [ ] Microcontrôleur 32 bits (STM32 / ARM), interruptions, timers
- [ ] RTOS
- [ ] Bus de terrain (CAN, Modbus, Ethernet industriel)
- [ ] IoT (LoRaWAN, Wi-Fi, MQTT)
- [ ] Conditionnement de capteurs, conversion A/N, filtrage numérique
- [ ] Projet de prototype embarqué → préciser en une ligne
**Métiers cibles** : ingénieur systèmes embarqués, logiciel industriel, IoT, validation électronique, automatisme.

### A3. Transition Énergétique
**Mots-clés ATS** : efficacité énergétique, audit énergétique, Bilan Carbone (scopes 1-2-3), décarbonation, transferts thermiques, échangeurs, pompes à chaleur, cogénération, méthode du pincement, hydrogène, biogaz, chaleur fatale, thermique du bâtiment (STD), CTA.
**À cocher (C / P / rien)** :
- [ ] Bilan Carbone / comptabilité énergétique
- [ ] Audit énergétique d'un site
- [ ] Dimensionnement échangeur / PAC / machine frigorifique
- [ ] Intégration thermique (pincement)
- [ ] Hydrogène / biogaz / récupération de chaleur fatale
- [ ] Simulation thermique dynamique (STD), CTA
- [ ] Étude technico-économique → préciser en une ligne
**Métiers cibles** : ingénieur efficacité énergétique, chef de projet décarbonation, bureau d'études thermiques / fluides, énergie.

### A4. Usine du Futur (UDF)
**Mots-clés ATS** : Lean Management, amélioration continue, excellence opérationnelle, 5S, Kaizen, SMED, VSM, gaspillages (Muda), TRS (OEE), cobotique, automatisation, MES, SCADA, données de production, génie industriel, ergonomie, flux.
**À cocher (C / P / rien)** :
- [ ] 5S
- [ ] Kaizen / chantier d'amélioration
- [ ] SMED
- [ ] VSM (cartographie des flux)
- [ ] TRS / OEE calculé
- [ ] 5 Pourquoi, Ishikawa, QRQC, 8D
- [ ] Management visuel, Takt Time, standards
- [ ] Réorganisation de ligne sur l'usine-école INEXO
- [ ] Programmation de cobot (Universal Robots)
- [ ] MES / SCADA / exploitation de données de production
- [ ] Ergonomie de poste, simulation de flux
**Métiers cibles** : ingénieur amélioration continue, méthodes / industrialisation, performance industrielle, production, supply chain, Lean (industrie, luxe, aéro, cosmétique, médical).

### A5. Énergies Renouvelables
**Mots-clés ATS** : photovoltaïque, éolien, hydraulique, géothermie, stockage (batteries Li-ion / LFP), smart grids, électronique de puissance, onduleurs, MPPT, raccordement réseau, ACV des équipements ENR.
**À cocher (C / P / rien)** :
- [ ] Dimensionnement d'une installation PV / éolienne
- [ ] Stockage batteries, gestion de l'intermittence
- [ ] Électronique de puissance (onduleur, hacheur, MPPT)
- [ ] Raccordement / réseau électrique
- [ ] ACV, recyclabilité des équipements
- [ ] Projet micro-réseau ou éco-conception → préciser en une ligne
**Métiers cibles** : ingénieur projets ENR, développement / exploitation de centrales, stockage, réseaux, bureau d'études électriques.

## B. Pathways — ECAM Engineering (CV et lettres souvent en anglais)

### B1. Robotics and Automation Engineering
**ATS keywords** : robotics, mechatronics, control systems, ROS, C++, OpenCV, computer vision, SLAM, MATLAB/Simulink, cobots, automation.
**À cocher** : [ ] cinématique / dynamique robot · [ ] asservissement · [ ] OpenCV / vision · [ ] SLAM / navigation · [ ] ROS · [ ] MATLAB/Simulink · [ ] projet robot mobile ou bras → préciser.

### B2. Sustainable Energy and Environmental Engineering
**ATS keywords** : sustainable process engineering, energy modelling, decarbonisation, LCA, carbon capture, environmental policy, thermal simulation, smart grids.
**À cocher** : [ ] modélisation de flux énergétiques · [ ] ACV / LCA (logiciel ?) · [ ] décarbonation industrielle · [ ] simulation thermique · [ ] étude de faisabilité → préciser.

### B3. Mechanical Engineering
**ATS keywords** : mechanical design, CAD, ANSYS, SolidWorks, FEA, CFD, continuum mechanics, vibration, test benches.
**À cocher** : [ ] CAO paramétrique (logiciel ?) · [ ] FEA (ANSYS ?) · [ ] CFD (logiciel ?) · [ ] vibrations · [ ] banc d'essai · [ ] projet aile / transmission / structure auto → préciser.

### B4. Industrial Engineering and Supply Chain Management
**ATS keywords** : supply chain management, inventory management, ERP / MRP, SAP, transport optimisation, Lean Six Sigma, WMS, flow simulation, VSM.
**À cocher** : [ ] modèles de stocks · [ ] ERP / MRP (SAP ?) · [ ] optimisation transport / réseau · [ ] Lean Six Sigma (formation, jamais « certifié ») · [ ] WMS · [ ] simulation de flux · [ ] VSM.
